# 🏛️ Council of AI (CSOAI)

**Independent AI-behaviour measurement. Open source. Bitcoin-anchored.**

## What We Do

CSOAI measures AI systems across22 governance axes, publishes signed evidence cards, and anchors proof to Bitcoin via Merkle trees. Every measurement is cryptographically verifiable.
